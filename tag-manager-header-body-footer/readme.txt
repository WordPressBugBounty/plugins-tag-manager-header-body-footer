All in one WordPress plugin - accessibility, tag manager, notes, floating contact buttons, back to top, cookie bar and more.

== Description ==

Infinity23 is an all-in-one WordPress plugin that combines accessibility tools, a tag manager, floating contact buttons, back to top, a cookie bar and more into a single settings panel, where each module can be turned on or off independently.

Modules you turn off are never loaded by the system, so your site stays fast and clean.

Learn more at [https://infinity23.com/](https://infinity23.com/)

= Why Infinity23 =

* One plugin instead of many - less code, fewer updates, fewer conflicts
* Every module can be included or excluded from a single screen
* Disabled modules load nothing at all - no CSS, no JS, no database calls
* Every module has its own on/off switch on top of the include/exclude system
* Exclude any module from specific pages by page ID
* Full control over colors, sizes, positions and mobile behaviour
* Built in Hebrew and RTL support
* No ads, no upsell popups inside your admin panel

= Free and Pro =

Infinity23 comes in a free version and a Pro version.

The free version includes the core modules and everything most sites need in order to run. The Pro version adds extra modules and advanced options on top of the free ones.

Pro features are clearly marked inside the plugin admin panel with a PRO label, so you always know what you are looking at. The plugin never nags you with popups or banners.

For the full and updated list of what is included in each version, visit [https://infinity23.com/](https://infinity23.com/)

== Modules ==

= Accessibility =

Adds a floating accessibility button that lets visitors adjust the page to their needs.

* Increase and decrease font size across the whole site
* Light contrast and high contrast display modes
* Highlight all links on the page
* Reset button that returns the site to its original state
* Link to your accessibility statement page
* Remembers the visitor choices between pages for a time period you set
* Custom button image, size, background color, border and border radius
* Separate button position for desktop and mobile
* Exclude any element from being changed using a CSS class
* All button texts can be translated to any language

= Tag Manager =

Insert tracking and verification codes anywhere on the page without touching your theme files.

* Insert code inside the head tags
* Insert code right after the opening body tag
* Insert code right before the closing body tag
* Unlimited code rows for each of the three positions
* Built in lazy loading for Google Analytics, Google Tag Manager, Facebook Pixel and Yandex Metrika
* Add your own custom JavaScript to the lazy loading queue
* Control after how many milliseconds the codes load when there is no user activity
* Exclude the codes from loading for admins or for all logged in users
* Exclude the codes from specific pages by page ID
* Storage notes area to keep old codes for later use
* PHP functions you can call from an external system outside of WordPress

= Page and Post Notes =

Leave internal notes on any page, post or custom post type. The notes are never shown to site visitors.

* Notes panel on pages, posts and custom post types
* Notes widget on the WordPress dashboard
* Multiple notes per page
* Switch each note between LTR and RTL direction
* Insert a separator line inside a note
* Notes column in the pages, posts and custom post types list tables so you can see which pages have notes
* Notes are saved automatically when the page is saved

= Floating WhatsApp Button =

Adds a floating WhatsApp button so visitors can message you in one click.

* Three built in button designs or your own custom image
* Pre filled message that opens inside the chat
* Full control over button size
* Separate position for desktop and mobile
* Open the chat in a new tab or the same tab
* Exclude the button from specific pages by page ID
* Hide on mobile or hide on desktop

= Phone Button =

Adds a floating click to call button.

* Solid color or gradient background
* Custom icon image with its own size control
* Button size, border and border radius controls
* Live preview while you edit the settings
* Separate position for desktop and mobile
* Exclude the button from specific pages by page ID

= Mobile Contact Line =

Adds a fixed contact bar at the bottom of the screen, built mainly for mobile.

* Phone, email, WhatsApp and chat buttons
* The chat button can point to any URL - a contact form, Waze, Google Maps, a Facebook page or anything else
* Each button has its own text, background color and width
* Set the display order of the buttons on the bar
* Email button can act as a mailto link or as a link to your contact page
* Pre filled WhatsApp message
* Full RTL support
* Exclude the bar from specific pages by page ID

= Back To Top Button =

Adds a floating button that scrolls the visitor back to the top of the page.

* Show the button only after the visitor scrolls a set distance
* Separate scroll distance for desktop and mobile
* Or keep the button always visible
* Custom icon image, size, background color, border and border radius
* Live preview while you edit the settings
* Separate position for desktop and mobile
* Exclude the button from specific pages by page ID

= Privacy Policy / Cookie Consent Bar =

Displays a cookie consent bar with an accept button that remembers the visitor choice.

* Custom message text with a placeholder for your privacy policy link
* Automatically loads the privacy policy page set in WordPress settings
* Custom bar colors, button colors and text colors
* Position the bar at the top or bottom, left or right
* Custom bar width in percent or pixels
* Separate position and width for mobile
* Set how many days the consent is remembered
* Exclude the bar from specific pages by page ID

= Show All Pages =

Displays everything on your site in one searchable admin view.

* Pages, posts, categories, tags, custom post types and WooCommerce items
* Published, private and scheduled items shown separately
* Search by title or by title and content
* Total count of every content type on your site
* Shows the Yoast SEO title, description, noindex and nofollow values when Yoast is installed
* Filter out pages without an SEO title or description
* Filter out pages excluded from the sitemap
* Show or hide any column
* Direct edit links, including an Elementor edit link when Elementor is installed
* Pagination with a selectable number of entries per page

= Show Pages IDs =

Displays page and post IDs everywhere in the WordPress admin.

* ID column in the pages, posts, media, comments, categories, tags and users tables
* ID column also available on any custom post type registered on your site
* ID shown in the admin bar on the front end
* ID added as a class on the body tag
* Works with WooCommerce products, product categories and product tags

= WordPress Settings =

Edit core site identity and editor behavior without leaving the plugin.

* Change the site logo, favicon, site name and site description
* Disable the Gutenberg block editor and use the classic editor instead
* Disable the block editor on the Widgets screen only
* Remove the default block library CSS from the front end
* Stop WordPress from creating multiple resized copies of every uploaded image
* Control how the image Title is set on upload and displayed in the Media Library
* Automatically rename uploaded images with non English file names

= Update Manager =

Take control of how plugins, themes and WordPress core update.

* Disable automatic updates for plugins, themes or WordPress core
* Force block updates for individual plugins or themes
* Hide the WordPress core update notice in the admin

= Email SMTP =

Route WordPress emails through an SMTP server instead of your server's default mail function.

* Connect Google, Amazon SES, Elastic Email, SendGrid, Mailgun, Maileroo or any custom SMTP server
* Choose the SMTP host, port and encryption method
* Optional username and password authentication
* Force a specific From email and From name and block other plugins from changing it
* Send a test email to confirm the connection works
* Optional email log that records every email sent, with retention and count limits

= Force SSL & HTTPS =

Force HTTPS on every request and fix mixed content warnings.

* Redirect all HTTP requests to HTTPS, including REST API requests
* Recognizes common reverse proxy and CDN headers so it never loops when SSL is terminated upstream
* Rewrite leftover http:// links in the page output to https://

= LLMs.txt & Robots.txt Editor =

Create and edit your llms.txt and robots.txt files directly from the WordPress admin.

* View, create, edit or delete the llms.txt file in your site root
* View, create, edit or delete the robots.txt file in your site root
* See the public URL for each file at a glance

= Plugins/Themes Downloader =

Download installed plugins and themes as ZIP files, no FTP access needed.

* One click download for any installed plugin or theme
* Optional download links added directly to the Plugins and Themes pages
* Include the version number in the downloaded file name
* Downloaded files are stored securely and cleaned up automatically

= Cron Management =

View and manage every scheduled task (WP-Cron) running on your site.

* See every currently scheduled cron event and when it will next run
* Run any cron event immediately or reschedule it to start now
* Pause a cron event without touching its underlying schedule
* Change a cron event's interval, with automatic revert when deactivated
* Keep a log of cron events that run on the site
* Trigger WP-Cron from an external service using a secure URL

= Redirect 301/302 =

Create and manage 301 and 302 redirects, organized into folders.

* Group redirects into folders for easier management
* Choose between 301 (permanent) and 302 (temporary) redirects
* Exact match or "contains" match redirect rules
* Choose whether to pass along the original URL's GET parameters
* Built in hit counter for every redirect
* Bulk insert multiple redirects at once
* Optional redirect log that records every fired redirect, including IP, country, browser and device

= LTR/RTL Direction Change =

Quickly flip the text direction of any admin screen.

* Adds a Direction button to the WordPress admin bar
* Switch any admin screen between LTR and RTL with one click
* Optionally remember the direction per page between reloads

= Folders Organizer =

Organize your Media Library, Pages, Posts and custom post types into folders.

* Separate folders system for each content type
* Move items between folders or leave them unassigned
* Choose which content types get a folders sidebar
* Works with any custom post type registered on your site

= Duplicate Pages =

Duplicate pages, posts and custom post types with one click.

* Duplicate link in the post list, in the admin bar (on the edit screen and when viewing the page on the site) and in the Bulk Actions menu to duplicate several items at once
* Works with pages, posts and custom post types - choose which types get the link
* Choose what is copied: title, slug, content, excerpt, featured image, status, publish date, author, password, page template, post format and menu order
* Copy taxonomies such as categories and tags
* Copy custom fields, including data saved by other plugins
* Separate option to copy or skip the Yoast SEO data
* List custom fields that must never be copied, with * as a wildcard
* Add a prefix or a suffix to the title of the copy
* The copy is created as a draft unless you choose to keep the original status
* Choose to stay on the list or open the new copy in the editor
* Only users who can edit the original item and create that content type can duplicate it

= Sticky Sidebar =

Keeps your theme sidebar in view while visitors scroll down the page.

* Choose the sidebar and the container by CSS class or ID
* Works with short sidebars and with sidebars taller than the window
* The sidebar stops at the bottom of the content area and never goes outside of it
* Set the space from the top and bottom of the window - the WordPress admin bar is added automatically
* Turn it off on screens smaller than a width you set
* Turns off automatically when your theme moves the sidebar under the content
* Keep the sidebar box at its full height while it moves, so its background and border stay in place
* Follows changes in the page height, such as images and content that load after the page
* Works on RTL sites
* Choose where it loads: front page, blog page, pages, posts, archives, search results and custom post types
* Exclude the sidebar from specific pages by page ID

== Frequently Asked Questions ==

= Do I need to activate each module separately? =

Yes. Every module can be enabled or disabled independently from the Include / Exclude screen, so you only load what you actually use.

= What happens to a module I turn off? =

Nothing is loaded. The module files are never included, so it does not add any CSS, JavaScript or database calls to your site.

= Can I use this plugin instead of the individual YYDevelopment plugins? =

Yes. This plugin is designed to replace the individual YYDevelopment plugins. Deactivate the individual plugins after activating this one to avoid conflicts.

= What is the difference between the free and the Pro version? =

The free version includes the core modules. The Pro version adds extra modules and advanced options on top of them. Pro features are marked with a PRO label inside the admin panel. See [https://infinity23.com/](https://infinity23.com/) for the updated list.

= How do I add header code into the site? =

Go to the Essential menu, open the Tag Manager page and insert your code in the head tags area.

= How do I add a WhatsApp button? =

Go to the Essential menu, open the WhatsApp Button page, enter your WhatsApp number and choose your button settings.

= How do I duplicate a page? =

Turn on the Duplicate Pages module in the Include / Exclude screen, then open its page from the Essential menu and activate it. A Duplicate link will appear under each item in your pages, posts and custom post types lists, in the admin bar and in the Bulk Actions menu.

= How do I make my sidebar sticky? =

Turn on the Sticky Sidebar module in the Include / Exclude screen, then open its page from the Essential menu and activate it. Enter the CSS class or ID of your theme sidebar, for example #secondary, and save. Leave the container empty unless the sidebar does not stay inside your content area.

= Can I hide a module on specific pages? =

Yes. Every module has an Exclude Pages By ID section where you can list the page IDs the module should not load on.

= Where do I find a page ID? =

Activate the Show Pages IDs module. The ID will then appear in the admin bar of every page and as a column in your admin lists.

= Does the plugin support Hebrew and RTL? =

Yes. The plugin ships with a Hebrew translation and all front end output adjusts automatically to RTL sites.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/infinity23` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to the Essential menu in your admin panel.
4. Open the Include / Exclude page and choose which modules you want to load.
5. Open each module page, turn it on and configure it.

== External services ==

Google Analytics / Tag Manager: loads when the Tag Manager module has an Analytics/GTM ID set, sends page URL on each page load. [Terms](https://policies.google.com/terms), [Privacy](https://policies.google.com/privacy).

Facebook Pixel: loads when the Tag Manager module has a Pixel ID set, sends page URL on each page load. [Terms](https://www.facebook.com/legal/terms), [Privacy](https://www.facebook.com/policy.php).

Yandex Metrika: loads when the Tag Manager module has a Metrika ID set, sends page URL on each page load. [Terms](https://yandex.com/legal/metrica_termsofuse), [Privacy](https://yandex.com/legal/confidential).

Elastic Email: sends the email's recipient, subject and body when the Email SMTP module sends a transactional email via Elastic Email's API. [Terms](https://elasticemail.com/resources/usage-policies/terms-of-use/), [Privacy](https://elasticemail.com/resources/usage-policies/privacy-policy/).

WhatsApp: the WhatsApp Button / Mobile Contact Line modules send the configured phone number and message to WhatsApp only when a visitor clicks the button. [Terms](https://www.whatsapp.com/legal/terms-of-service), [Privacy](https://www.whatsapp.com/legal/privacy-policy).
